# AGENTS.md

Правила для ИИ-агентов, которые работают с этим репозиторием.

## Что это

OpenCode Desktop-обвязка для универсальных Agent Skills:

- `.opencode/commands/` — команды, в теле только `$ARGUMENTS`;
- `.opencode/agents/` — скрытые агенты с английскими инструкциями;
- `skills/` — универсальные `SKILL.md`;
- `prompts/` — standalone-промпты.

## Правила

- Каждая команда должна иметь парного агента `cmd-<command>`.
- Команда должна содержать только `$ARGUMENTS`, без инструкций.
- Агент должен иметь `mode: primary` и `hidden: true`.
- Агент должен загружать существующий навык строкой ``Load the `skill-name` skill``.
- Не добавляйте секреты и персональные данные.
- Не копируйте сторонний текст без совместимой лицензии и атрибуции.

## Проверка

```bash
npm run validate
```

Проверяются навыки, команды, агенты и соответствие между ними.

## Стиль

- README и документация — по-русски.
- Содержимое навыков и агентов — по-английски.
- Без эмодзи и канцелярита.
